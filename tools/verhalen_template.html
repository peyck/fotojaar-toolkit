Fotojaar – verhalen

Het verhaal verschijnt pas nadat de speler geraden heeft, onder de foto. Een of twee zinnen volstaan: wie staat erop, wat is er bijzonder aan het karton, de fotograaf of het opschrift. Je mag het jaartal noemen. Links: plak een adres (https://…) of schrijf [linktekst](https://…). Met 📂 Toon in … open je de foto in Verkenner/Finder (enkel als je de pagina opent via python build.py verhalen). Klik daarna op Bewaar verhalen.json (komt in Downloads) en voer python build.py build en python build.py publish uit. Je werk wordt ook tussentijds in deze browser bewaard.
